# libtmux_easy examples

Bare-bones scripts: plain libtmux_easy, no tour scaffolding. For guided,
interactive tours see `../interactive/`.

| example | shows |
|---|---|
| `basic.py` | two windows of panes, a layout, `mode="wrap"`, `send_keys` by name, then attach |

Needs libtmux_easy importable: installed, or from a checkout
`../../.venv/bin/python basic.py`. Run outside tmux.
